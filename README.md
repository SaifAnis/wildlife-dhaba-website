# Wildlife Dhaba Website
A modern, countryside-themed Indian restaurant website featuring food, nature and a unique animal experience.

## About the Project
This project is a restaurant website designed to showcase a countryside dhaba where visitors can enjoy Indian food while experiencing different animals and birds.

## Features

- Home page with restaurant introduction
- About Us page
- Animal showcase featuring emus, ducks, chickens, goats and other animals
- Food menu with photographs and prices
- Restaurant and animal gallery
- Contact page with location and contact information
- Responsive website design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP

## Project Structure

- `assets/` – CSS, JavaScript and images
- `includes/` – Shared website components
- `index.php` – Homepage
- `about.php` – About the restaurant
- `animals.php` – Animal showcase
- `menu.php` – Restaurant menu
- `gallery.php` – Photo gallery
- `contact.php` – Contact information

## Running Locally

1. Install XAMPP.
2. Start Apache.
3. Place the project folder inside XAMPP's `htdocs` directory.
4. Open your browser.
5. Visit `http://localhost/DHABA/`.
